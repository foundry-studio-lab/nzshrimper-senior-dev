# senior-dev v0.4.2 (hardening + review runner) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the four logged hardening gaps and add `scripts/review-run.mjs`, one read-only, timeout-bounded, write-checked review runner for Codex and headless Claude.

**Architecture:** Four small edits to existing gate code (classifier, `openItems`, `set-tests`, the `--affected` base), each with its own tests. One new zero-dependency Node script that builds the review prompt, spawns the reviewer with `spawnSync`, checks for writes, extracts the JSON verdict and applies the retry/degrade rule. The conductor text then points at the runner instead of the manual Codex steps.

**Tech Stack:** Node ESM (`.mjs`), `node:test` + `node:assert/strict`, git CLI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-01-v0.4.2-hardening-review-runner-design.md`

## Global Constraints

- `scripts/lib/state.mjs` stays import-free of plugin files (the guard ships it alone as `state-lib.mjs`); node built-ins only.
- Repos without a tests config, and sessions started before 0.4.2, behave as in 0.4.1 except where spec §3 deliberately blocks more.
- The runner never writes senior-dev state; the conductor still records verdicts with `state-cli review`.
- Runner exit codes: `0` verdict printed, `3` degrade (print the `state-cli degrade` line), `4` write detected (no retry), `2` usage error.
- Timeouts are Node-enforced (`spawnSync` `timeout`, `killSignal: 'SIGTERM'`); macOS has no `timeout` command.
- Default timeouts: low/medium/haiku/sonnet 15 min, high/opus/fable 25 min, xhigh 40 min; `--timeout <minutes>` overrides; hidden `SENIOR_DEV_REVIEW_TIMEOUT_MS` overrides both (tests only).
- Claude lane command, exactly: `claude -p --model <tier> --permission-mode plan --allowedTools "Read,Grep,Glob,Bash(git diff:*),Bash(git show:*),Bash(git log:*)" --output-format text "<prompt>"`; binary override `SENIOR_DEV_CLAUDE_BIN`.
- Codex lane command: `node <companion> task --fresh --effort <e> "<prompt>"`; companion = newest `~/.claude/plugins/cache/*/codex/*/scripts/codex-companion.mjs`, override `SENIOR_DEV_CODEX_COMPANION`.
- Write-detected message starts `WRITE DETECTED: <reviewer> changed the repo during a read-only review`.
- set-tests refusal text, verbatim: `set-tests refused - this session already has test runs; changing the commands now would change what those runs mean. Rerun with --by-operator (the operator's yes) to change them anyway.`
- Status line, verbatim: `tests config changed mid-session (N)`.
- Session hygiene: file writes via Write/Edit (heredocs can be hook-blocked); one plain git command per Bash call; record `state-cli tests-green` in its own call before every commit; full suite is `node --test tests/*.test.mjs` (never bare `tests/`).

## Review Focus

1. **Dirty repo before the review, reviewer edits an already-modified file** — `git status --porcelain` is unchanged, so the runner must also compare a hash of `git diff HEAD --binary`; expected exit 4. Test in Task 5.
2. **Verdict line followed by trailing noise** (a closing code fence, a "done" line) — the last line that parses as the contract wins; expected exit 0 with the verdict. Test in Task 5.
3. **Invalid or unreadable `skills.json` while a session is open** — the stop gate catches every throw and exits 0, so a throw in `openItems` would silently disable it; expected: the gate still challenges with the non-test items. Test in Task 2.
4. **Nested substitution** `echo $(echo $(git push))` — expected `push`. Test in Task 1.
5. **A required per-reviewer flag missing** (`--reviewer claude` without `--model`, `--reviewer codex` without `--effort`) — expected exit 2 naming the flag, before anything is spawned. Test in Task 5.

  const push = { commit: false, integration: true };
  for (const c of ['git -C $(git rev-parse --show-toplevel) push', 'git -C $(pwd) push origin main',
    'echo $(git push)', 'echo `git push`', 'echo $(echo $(git push))']) {
    assert.deepEqual(classifyCommand(c), push, c);
  }
  assert.deepEqual(integrationTargets('git -C $(git rev-parse --show-toplevel) push'), [{ kind: 'push', dir: UNRESOLVED_DIR }]);
  assert.deepEqual(integrationTargets('git -C $(pwd) push origin main'), [{ kind: 'push', dir: UNRESOLVED_DIR }]);
  assert.deepEqual(integrationTargets('gh --repo $(echo o/r) pr create'), [{ kind: 'pr-create', dir: null }]);

  assert.deepEqual(classifyCommand('git commit -m "$(cat msg)"'), { commit: true, integration: false });

**Interfaces (exported for unit tests; CLI runs when invoked directly):**
- `buildPrompt(template: string, {range, phase, spec}) -> string` — fills `<RANGE>`, `<PHASE>`, `<SPEC>` in the text between the two `---` lines of `review-prompt.md`.
- `parseVerdict(stdout: string) -> object|null` — last line that `JSON.parse`s to an object with `verdict` ∈ {`APPROVED`,`NEEDS_REVISION`} and `Array.isArray(concerns)`.
- `timeoutMs({reviewer, effort, model, timeout}, env) -> number` — values per Global Constraints.
- `findCompanion(env, home) -> string|null` — override first, else newest glob match (sort by path; `tail -1` equivalent).
- CLI flags: `--reviewer codex|claude --phase <p> --range <a..b> [--spec <path>|none] [--effort <e>] [--model <m>] [--timeout <min>]`; `--spec` defaults to `none`.

Behaviour, per attempt (max 2): snapshot `{status: git status --porcelain, head: git rev-parse HEAD (or ''), diff: sha256 of git diff HEAD --binary}` in the checkout root (`git rev-parse --show-toplevel`); spawn; snapshot again; any difference → print `WRITE DETECTED: …` plus which of status/head/diff changed, exit 4. Spawn `ENOENT`, missing companion, or a non-zero exit whose output matches `/not logged in|log ?in|authenticat/i` → exit 3, no retry, degrade reasons `codex companion script not found` / `claude CLI not found` / `claude CLI not logged in`. Timeout (`result.error?.code === 'ETIMEDOUT'`) or `parseVerdict` null → retry once fresh. Second failure → exit 3 printing `state-cli degrade --wanted "<reviewer> review (phase <p>)" --used none --reason "<r>"`, where `<r>` is `timed out twice (<N> min each)`, `no JSON verdict twice`, or `<first>, then <second>`. Success → print the verdict JSON alone on stdout, exit 0.
